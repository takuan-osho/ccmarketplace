# Japanese Tech Writing Skill

A skill that defines writing norms for Japanese technical prose: book chapters, drafts, articles, and explanatory documents.

## Overview

This skill provides prescriptive rules for writing and revising Japanese technical manuscripts. It covers:

- **Formatting** - One sentence per line, code blocks, footnotes, bold for first-time term definitions
- **Paragraph and argument structure** - Paragraph writing with one topic per paragraph and explicit logical connections
- **Argument rigor** - Removing logical loopholes while preserving legitimate uncertainty
- **Reader load management** - Treating reader memory and attention as finite resources
- **Voice and narration** - Concrete subjects and consistent terminology
- **Restrained rhetoric** - Limiting dramatization and emphasis to where they earn their place
- **Banning LLM-style filler** - No empty phrases that add tone but no content
- **Removing redundancy** - One claim, stated once

Use it when writing or revising Japanese technical documents.

## Usage

The skill triggers automatically when drafting or revising Japanese technical prose. You can also invoke it explicitly:

```
/japanese-tech-writing
```
